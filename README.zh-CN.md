# 🎴 SillyTavern Multitools

[Tiếng Việt](README.md) | [English](README.en.md) | **简体中文** | [繁體中文](README.zh-TW.md)

> **一套用于翻译与制作 SillyTavern 角色卡的 5 合 1 工具 —— 完全在你自己的电脑上运行。**
> 由 **Guillichan × Sky** 打造。

专为**翻译者**和角色卡作者设计：用 AI 翻译角色卡，同时**不破坏代码、正则、世界书和宏**（如 `{{char}}` `{{user}}`）。

一切都在本地运行 —— 你的 **API 密钥不会被发送到任何地方**，没有任何中间服务器。

> 🌐 **语言与反馈：** 顶部**页眉**（所有工具通用）带有**界面语言切换 —— Tiếng Việt / English / 中文**，以及**🐞 报告错误**按钮（打开共享的报错表格，供大家记录 bug）。翻译卡、改卡、创建预设以及创建卡的主要面板均已支持三语；高级 MVU-ZOD Studio 面板和提取卡目前仍为越南语。

## 📦 里面有什么？

打开应用后，左侧栏可在 5 个工具之间切换。**随意切换 —— 正在运行的任务不会中断。**

| | 工具 | 用途 |
|---|---|---|
| 🌐 | **Dịch Card**（翻译卡） | 翻译角色卡。*这是主力工具。* |
| 🃏 | **Tạo Card**（创建卡） | 从小说生成新卡，另含世界书、正则、MVU/ZOD 变量、游戏界面。 |
| 🎛️ | **Tạo Preset**（创建预设） | 通过与 AI 对话，创建 / 修改 SillyTavern 预设与正则脚本。 |
| 🛠️ | **Mod Card**（改卡） | 按你的要求修改 / 扩写现有角色卡（续写、深挖……）。 |
| 🔍 | **Trích Card**（提取卡） | 读取小说 → 自动提取角色与世界书条目。 |

## 🚀 首次安装（只需做一次）

### 第 1 步 —— 安装两个基础软件
- **[Node.js](https://nodejs.org/)** —— 请选 **20 或更高**版本（像普通软件一样安装即可）。
- **[Git](https://git-scm.com/downloads)** —— 默认选项即可。

> 装完后建议**重启一次电脑**，以防万一。

### 第 2 步 —— 下载源码
打开**命令提示符**（按 Windows 键 → 输入 `cmd` → 回车），然后逐行粘贴：

```bash
cd C:\
git clone https://github.com/kubi2811/ST-Card-Translation-Sky.git
```

### 第 3 步 —— 运行
进入刚下载的文件夹，**双击 `start.bat`**。

- 第一次运行会**自动安装依赖**（需要几分钟 —— 请耐心等待，不要关闭）。
- 完成后会自动打开浏览器：**http://localhost:5173**。
- 会弹出几个**黑色小窗口** —— 那是 3 个辅助工具。**请不要关闭它们。**

> 之后每次只要双击 **`start.bat`** 就行了。

## 📖 翻译一张卡

### 1️⃣ 填入 API 密钥
左栏 **API Configuration** —— **Provider #1（主）** 框：
- 选择 **类型**（OpenAI Compatible / Anthropic / Google Gemini / Custom），粘贴 **Base URL**。
- 粘贴 **API Key** —— 每行一个（或用逗号分隔）；密钥越多越快，遇到 429 会自动轮换。
- 点击 **Load model** → 选 **主 Model**；开启 **副 Model** 让短条目走更快的模型。添加 **额外 Provider** 即可多家供应商并行。

> 💡 并行通道 = 所有供应商的 Σ(密钥数 × RPM)。应用会**自动遵守 RPM 限制**，不会被限流。

### 2️⃣ 载入角色卡 → 应用自动推荐配置
把 `.json`/`.png` 拖放到 **Card Preview**，或粘贴链接后载入。载入后应用会**自动分析卡片**并弹出**推荐弹窗**：
- 卡片含 **MVU 变量框架** / 重度界面脚本 → 推荐 **⚡ 轻量**；**大**卡 → **🚀 极速**；**小**卡 → **📖 完整**。
- 点 **"✅ 使用推荐配置"**（一键应用）或 **"保留当前设置"**。

> 正在翻译中途的卡（重新打开）会**自动恢复进度**，不再重复询问。

### 3️⃣ 选择翻译模式（3 个预设 —— 带 ★ 的是本卡推荐）

| 按钮 | 翻译什么 | 何时用 |
|---|---|---|
| **⚡ 轻量翻译** | 只翻玩家**看得到**的部分（关键词、开场白、卡名 / 世界书条目名、显示用正则）。卡内部 + MVU 变量保持原文 | 含重度 MVU / 游戏界面的卡 —— 快好几倍；AI 仍能读懂并用中文回复 |
| **📖 完整翻译** | 全部翻译 | 普通卡，想 100% 本地化 |
| **🚀 极速翻译** | 完整 + 把多个短条目合并成一次调用 | 大卡 / 条目多，追求最快 |

### 4️⃣ 点击 **翻译**
翻译前应用会自动处理（无需你操作）：
- **📖 自动人名术语表（第 0 阶段）：** 扫描反复出现的人名 / 术语，**一次调用**翻译好 → 所有通道共用（不再一个角色多个译名）。修仙/武侠术语较多的卡还会**自动加载标准术语包**。
- **♻ 复用旧译文：** 若你翻过该卡的旧版本，**未改动的内容**直接沿用旧译文（♻ 标记），只翻新增部分。

运行时可看**通道面板**（哪个模型在翻哪条、RPM、**🧮 真实输入/输出 token** 分模型 + 合计）。随时 **暂停 / 停止**；进度**自动保存**，关标签页重开还在。

### 5️⃣ 验收并导出
- **🩺 全面检查**（在导出框内）：一键运行**三项检查**（卡片健康 + 逐字段深度检查宏/括号/HTML/JSON + 与原卡对比）→ 给出 **通过 / 不通过** 结论；点任一问题即可**直接跳到对应字段**。
- **👁 SillyTavern 预览**（Card Preview 里的按钮）：查看翻译后的开场白，**和在 ST 里一模一样** —— 见下方 ✨。
- **导出** `.json` / `.png`（重新嵌回原始卡图）→ 直接丢进 SillyTavern 就能用。

> ### ✅ 给翻译者的推荐流程
> **翻译完 → 🩺 全面检查（抓静态错误）→ 👁 SillyTavern 预览 + 🧪 + ⇄ 对比双版（抓运行时错误）→ 修复出错的字段 → 导出。**

## ✨ 为什么翻译者会喜欢它

### 🔪 "外科手术式"翻译 —— 卡不会坏
应用**只翻译正文文字**，完整保留 HTML/CSS/JS、正则、链接、变量以及 `{{char}}` `{{user}}` 之类的宏 —— 手动或用普通 AI 翻译时坏卡基本都坏在这里。若检测到代码被插入杂字符，还有**自动修复守卫**。

### 👁 SillyTavern 预览 —— 界面和游玩时一模一样 ⭐
Card Preview 里的 **👁 SillyTavern 预览** 按钮。套用卡片的宏 + 显示用正则后渲染开场白，运行在**安全隔离的 iframe** 中（默认不跑脚本）：
- **🧪 运行脚本 + 测试数据：** 模拟真实的 TavernHelper / MVU 环境（与真正的 JS-Slash-Runner 扩展一致）→ **脚本驱动的状态栏 / 游戏界面会自动填数**，无需导入即可看到和 ST 里一样的界面。**脚本错误即时显示 + 追溯到确切的正则/字段 + ↪ 跳到字段按钮** 便于修改译文。
- **🎲 AI 生成测试数据：** 未游玩的卡（变量全为默认）或**没有 `[initvar]`** 的卡 → 调用 AI 填入**真实示例值**（AI 只改数值，保留变量名）→ 状态栏显示真实数字。
- **⇄ 对比双版：** 原文 | 译文 **并排运行** —— 两边都报错 = 卡片**本来就有的 bug**；只有译文报错 = **翻译造成的** bug。

### ⚡ 多通道 + 🧮 真实 token 统计
多密钥 × 多供应商 = 大量请求并行；通道一空闲立刻领下一条，仍严格遵守 **RPM 限制**（无 429）。面板 + 运行结束日志显示从 API 读取的**真实输入/输出 token** —— 精确知道消耗多少（共用密钥时尤其有用）。

### ♻ 翻译卡片更新 —— 只翻改动 ⭐
作者更新了原版？无需整卡重翻。**两种方式：**
- **自动：** 载入新版本，应用扫描你的旧缓存，将**未改动内容**直接沿用（♻ 标记），只留新增部分待翻。
- **手动 —— 🔀 卡片对比**（Card Preview 上方按钮）：载入 3 个文件 **Card Raw**（旧原文）、**Card 译文**、**Card Final**（新原文）→ **智能合并** → 预览（♻ 绿=复用，✏️ 橙=待翻）→ **送去翻译卡** 只翻新增部分。也可并排查看 3 个版本、就地编辑、按"仅显示差异"筛选。

### 🧠 保持一致性
- **📖 自动人名术语表** + 内置 **📚 修仙/武侠术语包**（92 条，卡片匹配时自动加载）—— 全卡人名与术语统一。
- **术语表（Glossary）** —— 强制 AI 按你的要求翻译人名和专有名词（你的条目始终优先）。
- **翻译记忆** —— 相同的句子得到相同的译文。
- **MVU / EJS 同步** —— 代码里和世界书里的变量名始终保持一致。

## ❓ 常见问题

**点"更新"报错 / 卡住**
→ 见上文[更新版本](#-更新版本)，用那 3 条手动命令。

**应用提示 `Failed to resolve import ...`**
→ 新版本增加了依赖库。彻底关闭应用后重新运行 **`start.bat`**（它会自动安装）。仍不行就在安装目录里运行 `npm install`。

**载入卡之后应用卡顿几秒**
→ 那张卡的正则脚本非常大（几百 KB）。这是正常现象，稍等即可。若不需要翻译脚本，可在第 3 步取消勾选 **Regex** 分组。

**连不上 API / 报 CORS 错误**
→ 检查 Base URL 与 Key，试试开启 **CORS Proxy**，或点 **Test Connection** 查看具体错误。

**扩写超大条目时 Gemini 返回 524 / 超时**
→ 单次请求耗时过长，代理超时了。请对整个段落使用**扩写模式**（应用会自动分段），或改选一个更小的区块来深挖。

**`start.bat` 弹出的黑色小窗口是什么？**
→ 是 3 个辅助工具（创建卡 / 创建预设 / 改卡）。**请勿关闭**，否则那几个工具打不开。
