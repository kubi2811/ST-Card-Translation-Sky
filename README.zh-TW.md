# 🎴 SillyTavern Multitools

[Tiếng Việt](README.md) | [English](README.en.md) | [简体中文](README.zh-CN.md) | **繁體中文**

> **一套用於翻譯與製作 SillyTavern 角色卡的 5 合 1 工具 —— 完全在你自己的電腦上執行。**
> 由 **Guillichan × Sky** 打造。

專為**翻譯者**與角色卡作者設計：用 AI 翻譯角色卡，同時**不破壞程式碼、正規表示式、世界書與巨集**（如 `{{char}}` `{{user}}`）。

一切都在本機執行 —— 你的 **API 金鑰不會被傳送到任何地方**，沒有任何中間伺服器。

> 🌐 **語言與回報：** 頂部**頁首**（所有工具通用）具有**介面語言切換 —— Tiếng Việt / English / 中文**，以及**🐞 回報錯誤**按鈕（開啟共用的錯誤回報表格，供大家記錄 bug）。翻譯卡、改卡、建立預設以及建立卡的主要面板皆已支援三語；進階 MVU-ZOD Studio 面板與擷取卡目前仍為越南語。

## 📦 裡面有什麼？

開啟應用程式後，左側欄可在 5 個工具之間切換。**隨意切換 —— 正在執行的工作不會中斷。**

| | 工具 | 用途 |
|---|---|---|
| 🌐 | **Dịch Card**（翻譯卡） | 翻譯角色卡。*這是主力工具。* |
| 🃏 | **Tạo Card**（建立卡） | 從小說生成新卡，另含世界書、正規表示式、MVU/ZOD 變數、遊戲介面。 |
| 🎛️ | **Tạo Preset**（建立預設） | 透過與 AI 對話，建立 / 修改 SillyTavern 預設與正規表示式腳本。 |
| 🛠️ | **Mod Card**（改卡） | 依你的要求修改 / 擴寫既有角色卡（續寫、深掘……）。 |
| 🔍 | **Trích Card**（擷取卡） | 讀取小說 → 自動擷取角色與世界書條目。 |

## 🚀 首次安裝（只需做一次）

### 第 1 步 —— 安裝兩個基礎軟體
- **[Node.js](https://nodejs.org/)** —— 請選 **20 或更新**的版本（像一般軟體那樣安裝即可）。
- **[Git](https://git-scm.com/downloads)** —— 使用預設選項即可。

> 裝完後建議**重新開機一次**，以防萬一。

### 第 2 步 —— 下載原始碼
開啟**命令提示字元**（按 Windows 鍵 → 輸入 `cmd` → Enter），然後逐行貼上：

```bash
cd C:\
git clone https://github.com/kubi2811/ST-Card-Translation-Sky.git
```

### 第 3 步 —— 執行
進入剛下載的資料夾，**按兩下 `start.bat`**。

- 第一次執行會**自動安裝相依套件**（需要幾分鐘 —— 請耐心等待，不要關閉）。
- 完成後會自動開啟瀏覽器：**http://localhost:5173**。
- 會跳出幾個**黑色小視窗** —— 那是 3 個輔助工具。**請不要關閉它們。**

> 之後每次只要按兩下 **`start.bat`** 就好了。

## 📖 翻譯一張卡

### 1️⃣ 填入 API 金鑰
左欄 **API Configuration** —— **Provider #1（主）** 框：
- 選擇 **類型**（OpenAI Compatible / Anthropic / Google Gemini / Custom），貼上 **Base URL**。
- 貼上 **API Key** —— 每行一組（或用逗號分隔）；金鑰越多越快，遇到 429 會自動輪替。
- 按 **Load model** → 選 **主 Model**；開啟 **副 Model** 讓短條目走更快的模型。新增 **額外 Provider** 即可多家供應商並行。

> 💡 並行通道 = 所有供應商的 Σ(金鑰數 × RPM)。應用程式會**自動遵守 RPM 限制**，不會被限流。

### 2️⃣ 載入角色卡 → 應用程式自動推薦設定
把 `.json`/`.png` 拖放到 **Card Preview**，或貼上連結後載入。載入後應用程式會**自動分析卡片**並彈出**推薦視窗**：
- 卡片含 **MVU 變數框架** / 重度介面腳本 → 推薦 **⚡ 輕量**；**大**卡 → **🚀 極速**；**小**卡 → **📖 完整**。
- 按 **「✅ 使用推薦設定」**（一鍵套用）或 **「保留目前設定」**。

> 正在翻譯到一半的卡（重新開啟）會**自動還原進度**，不再重複詢問。

### 3️⃣ 選擇翻譯模式（3 個預設 —— 帶 ★ 的是本卡推薦）

| 按鈕 | 翻譯什麼 | 何時用 |
|---|---|---|
| **⚡ 輕量翻譯** | 只翻玩家**看得到**的部分（關鍵詞、開場白、卡名 / 世界書條目名、顯示用正則）。卡內部 + MVU 變數保持原文 | 含重度 MVU / 遊戲介面的卡 —— 快好幾倍；AI 仍能讀懂並用目標語言回覆 |
| **📖 完整翻譯** | 全部翻譯 | 一般卡，想 100% 在地化 |
| **🚀 極速翻譯** | 完整 + 把多個短條目合併成一次呼叫 | 大卡 / 條目多，追求最快 |

### 4️⃣ 按下 **翻譯**
翻譯前應用程式會自動處理（不用你動手）：
- **📖 自動人名術語表（第 0 階段）：** 掃描反覆出現的人名 / 術語，**一次呼叫**翻好 → 所有通道共用（不再一個角色多個譯名）。修仙／武俠術語較多的卡還會**自動載入標準術語包**。
- **♻ 沿用舊譯文：** 若你翻過該卡的舊版本，**未變動的內容**直接沿用舊譯文（♻ 標記），只翻新增部分。

執行時可看**通道面板**（哪個模型在翻哪條、RPM、**🧮 真實輸入/輸出 token** 分模型 + 合計）。隨時 **暫停 / 停止**；進度**自動儲存**，關分頁重開還在。

### 5️⃣ 驗收並匯出
- **🩺 全面檢查**（在匯出框內）：一鍵執行**三項檢查**（卡片健康 + 逐欄位深度檢查巨集/括號/HTML/JSON + 與原卡比對）→ 給出 **通過 / 未通過** 結論；點任一問題即可**直接跳到對應欄位**。
- **👁 SillyTavern 預覽**（Card Preview 裡的按鈕）：查看翻譯後的開場白，**和在 ST 裡一模一樣** —— 見下方 ✨。
- **匯出** `.json` / `.png`（重新嵌回原始卡圖）→ 直接丟進 SillyTavern 就能用。

> ### ✅ 給翻譯者的推薦流程
> **翻完 → 🩺 全面檢查（抓靜態錯誤）→ 👁 SillyTavern 預覽 + 🧪 + ⇄ 對比雙版（抓執行期錯誤）→ 修復出錯的欄位 → 匯出。**

## ✨ 為什麼翻譯者會喜歡它

### 🔪 「外科手術式」翻譯 —— 卡不會壞
應用程式**只翻譯正文文字**，完整保留 HTML/CSS/JS、正規表示式、連結、變數以及 `{{char}}` `{{user}}` 之類的巨集 —— 手動或用一般 AI 翻譯時壞卡幾乎都壞在這裡。若偵測到程式碼被插入雜字元，還有**自動修復守衛**。

### 👁 SillyTavern 預覽 —— 介面和遊玩時一模一樣 ⭐
Card Preview 裡的 **👁 SillyTavern 預覽** 按鈕。套用卡片的巨集 + 顯示用正則後渲染開場白，執行在**安全隔離的 iframe** 中（預設不跑腳本）：
- **🧪 執行腳本 + 測試資料：** 模擬真實的 TavernHelper / MVU 環境（與真正的 JS-Slash-Runner 擴充功能一致）→ **腳本驅動的狀態列 / 遊戲介面會自動填數**，無需匯入即可看到和 ST 裡一樣的介面。**腳本錯誤即時顯示 + 追溯到確切的正則/欄位 + ↪ 跳到欄位按鈕** 便於修改譯文。
- **🎲 AI 生成測試資料：** 未遊玩的卡（變數全為預設）或**沒有 `[initvar]`** 的卡 → 呼叫 AI 填入**真實範例值**（AI 只改數值，保留變數名）→ 狀態列顯示真實數字。
- **⇄ 對比雙版：** 原文 | 譯文 **並排執行** —— 兩邊都報錯 = 卡片**本來就有的 bug**；只有譯文報錯 = **翻譯造成的** bug。

### ⚡ 多通道 + 🧮 真實 token 統計
多金鑰 × 多供應商 = 大量請求並行；通道一空閒立刻領下一條，仍嚴格遵守 **RPM 限制**（無 429）。面板 + 執行結束記錄顯示從 API 讀取的**真實輸入/輸出 token** —— 精確知道消耗多少（共用金鑰時尤其有用）。

### ♻ 翻譯卡片更新 —— 只翻改動 ⭐
作者更新了原版？無需整卡重翻。**兩種方式：**
- **自動：** 載入新版本，應用程式掃描你的舊快取，將**未變動內容**直接沿用（♻ 標記），只留新增部分待翻。
- **手動 —— 🔀 卡片比對**（Card Preview 上方按鈕）：載入 3 個檔案 **Card Raw**（舊原文）、**Card 譯文**、**Card Final**（新原文）→ **智慧合併** → 預覽（♻ 綠=沿用，✏️ 橘=待翻）→ **送去翻譯卡** 只翻新增部分。也可並排檢視 3 個版本、就地編輯、依「只顯示差異」篩選。

### 🧠 維持一致性
- **📖 自動人名術語表** + 內建 **📚 修仙/武俠術語包**（92 條，卡片相符時自動載入）—— 全卡人名與術語統一。
- **術語表（Glossary）** —— 強制 AI 依你的要求翻譯人名與專有名詞（你的條目始終優先）。
- **翻譯記憶** —— 相同的句子得到相同的譯文。
- **MVU / EJS 同步** —— 程式碼裡與世界書裡的變數名稱始終保持一致。

## ❓ 常見問題

**按「更新」出錯 / 卡住**
→ 見上方[更新版本](#-更新版本)，改用那 3 條手動指令。

**應用程式顯示 `Failed to resolve import ...`**
→ 新版本增加了相依套件。完全關閉應用程式後重新執行 **`start.bat`**（它會自動安裝）。仍不行就在安裝目錄執行 `npm install`。

**載入卡之後應用程式卡頓幾秒**
→ 那張卡的正規表示式腳本非常大（好幾百 KB）。這是正常現象，稍等即可。若不需要翻譯腳本，可在第 3 步取消勾選 **Regex** 群組。

**連不上 API / 出現 CORS 錯誤**
→ 檢查 Base URL 與 Key，試著開啟 **CORS Proxy**，或按 **Test Connection** 查看確切錯誤。

**擴寫超大條目時 Gemini 回傳 524 / 逾時**
→ 單次請求耗時過長，Proxy 逾時了。請對整個段落使用**擴寫模式**（應用程式會自動分段），或改選一個較小的區塊來深掘。

**`start.bat` 跳出的黑色小視窗是什麼？**
→ 是 3 個輔助工具（建立卡 / 建立預設 / 改卡）。**請勿關閉**，否則那幾個工具打不開。
