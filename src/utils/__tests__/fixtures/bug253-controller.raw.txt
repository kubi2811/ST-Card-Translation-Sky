【变量输出格式 · 强制固定格式】

**三处必须完全一致：**
1. 外层标签 `<UpdateVariable>` 开头、`</UpdateVariable>` 结尾（大小写敏感）
2. 说明标签 `<Analysis>` … `</Analysis>`
3. 数据标签 `<JSONPatch>` … `</JSONPatch>`

**`<JSONPatch>` 与 `</JSONPatch>` 之间必须是一个 JSON 数组 `[ … ]`。**
数组里每一项是一个操作对象；数组前后不得有其它任何内容。

---

## 二、五种合法 op（**逐字小写，不得改写**）

| op 拼写 | 用途 | value 类型 |
|---|---|---|
| `replace` | 覆盖为一个新值 | 任意 |
| `delta` | **数值增减**（唯一合法方式） | **数字**，正数加、负数减 |
| `insert` | 新增一个键（对象加键 / 数组追加） | 任意 |
| `add` | `insert` 的同义词，效果完全相同 | 任意 |
| `remove` | 删除一个键 | **不写 value** |

**每一轮：新增键一律用 `insert`；数值变化一律用 `delta`。**

---

## 三、三条路径规则（写死）

1. **路径逐层用 `/` 分隔，每层都有前导斜杠。**
   - 正确：`/玩家/状态/精力`、`/物资/避难所内/食物与水/方便面/count`
   - 错误：用点号连接各层（`.` 是**禁用字符**，见下条）
2. **键名里禁止出现这 9 个字符**：
   `.`　`/`　空格　`:`　`，`　`、`　`（`　`）`　`"`　`<`　`>`
   需要分隔语义时改用 `_` 或 `-`，例如 `暴风雪_20260320`、`21-40岁`
   **禁止使用 `<占位符>` 形式**（如 `<避难所名>`）—— 那是说明文字，不是真实键名
3. **必须先有父对象再写子键。** 父对象不存在时，先用 `insert` 建父对象，再写子键。
   新建避难所时，必须一次性 `insert` 完整的避难所对象（含 科技 / 规则 / 臣民统计 三项）。

---

## 四、会被【静默丢弃】的写法（不报错，但变量完全不会更新 —— 绝对禁止）

> 以下均为**反面清单**，请勿模仿。为防误抄，此处故意不写完整 JSON。

1. ❌ **op 拼写用任何大写或首字母大写**：如 `Replace`、`REPLACE`、`Delta`、`Insert`
2. ❌ **op 使用下列不被识别的动词**：
   `set`　`update`　`assign`　`delete`　`unset`　`merge`　`push`　`copy`
3. ❌ **`JSONPatch` 标签内放对象而不是数组**（缺少外层方括号）
4. ❌ **在数组外再包一层对象键**（例如把数组塞进一个名为 `json_patch` 的键里）
5. ❌ **写命令式代码**：`_.set(...)`、`_.update(...)`、`_.assign(...)` 等一律无效
6. ❌ **拆成多个 `JSONPatch` 块**（虽然可解析，但极易出错，禁止）
7. ❌ **`Analysis` 内出现尖括号**
8. ❌ **路径用点号分隔** —— 会被当成**单个键名**：既更新不了原值，还会在顶层留下垃圾键
9. ❌ **新增键时用 `replace`** —— 该键不存在时会被静默丢弃，必须用 `insert`
10. ❌ **`remove` 操作却带了 value 字段**

---

## 五、数值一律用 `delta`，禁止手算

正确：`{"op":"delta","path":"/玩家/状态/精力","value":-5}`
错误：先算出新值再 `replace`（会因并发/顺序问题写错）

## 七、`臣民统计` 的合法键名（**逐字写死，不得增删、不得改写**）

`臣民统计` **不在 玩家 下，而在每个避难所里**：`/避难所/<实际避难所名>/臣民统计/...`
（`<实际避难所名>` 是说明，实际要写真实名字，如 `城南小学避难所`）

```
职业:      技术工人　文职人员　高级知识分子　安保　普通劳动力　老弱病残
性别:      男性　女性
年龄.男性:  20岁以下　21-40岁　41-60岁　60岁以上
年龄.女性:  20岁以下　21-40岁　41-60岁　60岁以上
女性状态:   处女　非处女　生理期　怀孕
囚犯:      男性　女性
特殊统计:   20岁以下处女　21-40岁处女
```

**六个分组名**：`职业`　`性别`　`年龄`　`女性状态`　`囚犯`　`特殊统计`

**禁止使用的错误写法**：

| 禁止写 | 应写 |
|---|---|
| 把 `臣民统计` 放在 `/玩家/状态/` 下 | 放在 `/避难所/<实际名>/` 下 |
| `年龄/20岁以下`（不分男女） | `年龄/男性/20岁以下` 或 `年龄/女性/20岁以下` |
| `未成年` / `学生` | `20岁以下` |
| `50岁以上` | `60岁以上` |
| `已孕` | `怀孕` |
| `未孕` | `非处女` |
| `21-30岁` / `31-40岁` | `21-40岁` |
| `41-50岁` / `51-60岁` | `41-60岁` |
| `囚犯`（不分男女） | `囚犯/男性` 或 `囚犯/女性` |

**已废弃、不得再用的路径**：`/避难所/<避难所名>/臣民统计`、`/避难所/<避难所名>/人口`、
`/避难所/<避难所名>/人口`、`/避难所/<避难所名>/人口`、`/物资/避难所内/其他杂物/*`、`/人物/*`、`/人物/*`、

## 九、自检清单（每轮输出前逐条确认）

1. 三个标签拼写与大小写完全正确？
2. `JSONPatch` 里是**数组**、不是对象、没有多包一层？
3. 每个 op 都是 `replace` / `delta` / `insert` / `add` / `remove` 之一且全小写？
4. 每条 path 都逐层用 `/` 分隔，键名里没有那 9 个禁用字符、也没有 `<占位符>`？
5. 数值变化全部用 `delta`？
6. 新增键全部用 `insert`，且父对象已存在？
7. `臣民统计` 写在 `/避难所/<实际名>/臣民统计` 下，键名与第七节**逐字一致**（年龄与囚犯分男女）？
8. `remove` 操作**没有** value 字段？
